# ⚛ Phyzzy

**Интерактивная энциклопедия физики для школьников** — понятно, с формулами, схемами и задачами.

🌐 **Сайт:** https://gochamixin-gif.github.io/Phyzzy/

---

## Что внутри

- 📚 **120+ статей** — от строения вещества до квантовой механики
- 🎯 **40+ задач** — с подсказками и проверкой ответа
- 📝 **20 тестов** — 100 вопросов с выбором из 4 вариантов
- 🔬 **11 лабораторных** — по учебнику Перышкина 7 класса
- 📐 **Справочник СИ** — единицы, приставки, переводы
- ✅ **Прогресс** — отметки о прочитанном и решённом

---

## Технологии

- HTML5 + CSS3 + Vanilla JavaScript
- ES-модули
- localStorage для прогресса
- Без фреймворков и сборки
